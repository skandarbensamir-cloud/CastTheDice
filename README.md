# CastTheDice 🎲

A simple dice game built as a C# console application – my first project in the .NET Cloud Developer program at IT-Högskolan.

## How to play
1. Enter your name and confirm that you understand the rules
2. Two dice are rolled
3. If the sum is **12**, you win!
4. Otherwise, press **Enter** to roll again – or type **nej** to quit

## What I practiced
- Reading user input with `Console.ReadLine` and `Console.ReadKey`
- Conditions with `if / else if / else`
- Loops with `while` to keep the game running
- Random numbers with `Random`
- Colored console output

## How to run
Requires the .NET 10 SDK.

    dotnet run

*The in-game text is in Swedish.*
